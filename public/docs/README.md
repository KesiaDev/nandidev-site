# 📁 Pasta de Documentos

## 📄 ConectaQ.pdf

Coloque o arquivo PDF de apresentação do ConectaQ aqui com o nome:
- `ConectaQ.pdf`

O arquivo será acessível em: `/docs/ConectaQ.pdf`

## 📝 Como adicionar o PDF:

1. Copie o arquivo `ConectaQ.pdf` para esta pasta (`public/docs/`)
2. Certifique-se de que o nome do arquivo está exatamente como: `ConectaQ.pdf`
3. O botão "Ver Apresentação" no site irá abrir o PDF automaticamente
