# 📸 Como Adicionar a Imagem do ConectaQ

## 🎯 Objetivo
Adicionar a primeira página do PDF (ou uma imagem promocional) do ConectaQ para aparecer no card em vez do gradiente verde.

## 📁 Onde Colocar a Imagem

Coloque a imagem em:
```
public/logo/conectaq-hero.jpg
```

## 📝 Formatos Aceitos
- `.jpg` ou `.jpeg` (recomendado)
- `.png`
- `.webp`

## 🔧 Como Obter a Imagem

### Opção 1: Extrair do PDF
1. Abra o PDF `ConectaQ.pdf`
2. Vá na primeira página
3. Tire um screenshot ou exporte como imagem
4. Salve como `conectaq-hero.jpg` em `public/logo/`

### Opção 2: Usar Ferramenta Online
1. Use um conversor PDF para imagem (ex: ilovepdf.com)
2. Converta a primeira página do PDF para JPG
3. Salve como `conectaq-hero.jpg` em `public/logo/`

### Opção 3: Usar Adobe Acrobat ou Similar
1. Abra o PDF
2. Exporte a primeira página como imagem
3. Salve como `conectaq-hero.jpg` em `public/logo/`

## ✅ Após Adicionar

A imagem aparecerá automaticamente no card do ConectaQ, substituindo o gradiente verde.

## 📐 Tamanho Recomendado

- **Largura**: 800px - 1200px
- **Altura**: 400px - 600px
- **Proporção**: 16:9 ou similar
- **Peso**: Máximo 500KB (otimize se necessário)

## 🎨 Dica

Se a imagem for muito grande, você pode usar ferramentas online para redimensionar:
- TinyPNG.com
- Squoosh.app
- ImageOptim
